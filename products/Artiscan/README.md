# Artiscan

> Transform boring barcodes into artistic SVG designs.

## What it does
Traditional barcodes are visually unappealing and can detract from the overall design aesthetics.

## Tech Stack
- **Framework**: Next.js 14 App Router
- **Styling**: Tailwind CSS
- **Analytics**: PostHog
- **Deployment**: Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Set up environment (copy and fill in your PostHog key)
cp .env.local.example .env.local

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
